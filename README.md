#  Estuda+

Landing page desenvolvida como parte do desafio de HTML e CSS da DIO. O Estuda+ é um projeto fictício de uma plataforma que ajuda estudantes a organizarem sua rotina de estudos com mais eficiência e motivação.

##  Funcionalidades

- Seção principal com chamada para ação (CTA)
- Apresentação das principais funcionalidades do app
- Seção "Sobre o Estuda+" com texto descritivo
- Página de login fictícia com formulário estilizado ( login não funcional )
- Layout responsivo e visual moderno

##  Tecnologias utilizadas

- HTML5
- CSS3
